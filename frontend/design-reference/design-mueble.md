# African Fashion Marketplace - Mueble Style Redesign

## Design System

### Color Palette
| Token | Value | Usage |
|-------|-------|-------|
| `--background` | `#ffffff` | Primary background |
| `--foreground` | `#1a237e` | Primary text (navy blue) |
| `--primary` | `#1a237e` | Navy blue accent |
| `--accent` | `#00c853` | Green CTA buttons |
| `--accent-hover` | `#00b248` | Green hover state |
| `--text-muted` | `#666666` | Secondary text |
| `--text-light` | `#999999` | Tertiary text |
| `--border` | `#e0e0e0` | Border color |
| `--footer-bg` | `#1a237e` | Dark blue footer |

### Typography
- **Headings**: Playfair Display (serif) - elegant
- **Body**: Inter (sans-serif) - clean
- **Hero Title**: 48-64px, bold
- **Section Title**: 36-42px, bold
- **Card Title**: 18-20px, semibold
- **Body**: 16px, regular
- **Small/Caption**: 14px, regular

### Layout
- **Full-width sections** (board to border screen)
- **No max-width containers** for hero/images
- **Content containers**: max-width 1400px, centered
- **Section padding**: 80px vertical

## Sections

### 1. Navbar
- Fixed top, white background
- Logo centered
- Category tabs: All, Dresses, Fabrics, Accessories, Designers
- Right: Search, Cart, Menu icons
- Full width, border-bottom

### 2. Hero
- Full-width hero section
- Large background image (full bleed)
- Left overlay card with:
  - "Discover our new Collection"
  - "Shop from $49"
  - Green CTA button
- Product list overlay with thumbnails
- Navigation arrows

### 3. Category Showcase (Inspiration)
- Two large category cards side by side
- Full-width images
- Text overlay with category name and CTA
- "—Find crafted fabrics your wardrobe will love"

### 4. Latest Products
- Section title: "Latest products added"
- 4-column product grid
- Product cards with:
  - Image
  - Category tag
  - Product name
  - Price
  - Green "View more" button
- "New" badge on new items

### 5. Journal / Blog
- Section title: "Latest Posts"
- 3 blog cards
- Image with text overlay card below
- Category tag (Promos/News)
- Title with dash prefix
- "read more" link

### 6. Features
- 4 feature cards in a row
- Icons
- Title + description
- Border separators

### 7. Instagram Feed
- Full-width image strip
- "—Instagram" label
- "Follow us @AfricanFashion"

### 8. Footer
- Dark blue background (#1a237e)
- 4 columns:
  - Logo + description + social icons
  - Menu links
  - Store links
  - Newsletter signup
- Featured products list
- Bottom bar with credits
